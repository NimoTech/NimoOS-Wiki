NimoOS's **visible long-term memory** — maintains a `.wiki.md` navigation map inside your storage so both you and the agent can read what is on the NAS, where it lives, and what it is about.

## What this is
Binds localhost and is fronted by the NimoOS gateway under `/v1/wiki`.

## Capabilities

| Capability | Notes |
|---|---|
| `.wiki.md` navigation map | Maintained in place, readable with any editor |
| Multiple roots | Choose which directories are covered; each can be enabled or disabled |
| Incremental upkeep | Follows file changes; large directories go through rate-limited background indexing |
| Summaries | Generated by a local or cloud model |

## Relationship to other services

Wiki is one part of the NimoOS retrieval stack, alongside `NimoOS-Search`
(retrieval aggregation), `NimoOS-Parser` (parsing and embedding) and
`NimoOS-AI` (the agent that consumes it).


## Building

This repository builds on its own — every dependency, including
[NimoOS-Common](https://github.com/NimoTech/NimoOS-Common), is an ordinary
published Go module.

```bash
CGO_ENABLED=1 go build ./...   # go-systemd needs CGO
go test ./...
```

Go services pin `go 1.21` and echo v4.12 — **do not run `go mod tidy`**.

To work on NimoOS-Common and this service at the same time, put a `go.work` in
the directory containing both checkouts rather than adding a `replace` to
`go.mod` — that keeps a local path out of the shared module file.
